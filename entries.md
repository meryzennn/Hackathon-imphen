# Catatan Entri

Semua entri yang disubmit tim dicatat di sini. Satu baris = satu entri.
Sebelum submit, cek dulu pakai `tools/normalize.py --check entries.md <link>`
supaya tidak dobel dengan entri tim sendiri.

## Ringkasan

- Total disubmit: 0
- Valid (+1): 0
- Menunggu penilaian: 0
- Duplikat (0): 0
- Ditolak (0): 0
- **Poin saat ini: 0**

## Daftar entri

| No | Link disubmit | Bentuk catat | Jam submit (WIB) | Status | Catatan / alasan |
|---|---|---|---|---|---|
| 1 | _contoh: https://www.SitusJudi.xyz/_ | `situsjudi.xyz` | _2026-12-05 00:10_ | Menunggu penilaian | _hapus baris contoh ini_ |

## Cara mengisi

- **Link disubmit**: tulis persis seperti yang dikirim ke form resmi.
- **Bentuk catat**: hasil normalisasi dari `tools/normalize.py` (yang dipakai panitia untuk cek duplikat).
- **Jam submit**: waktu kirim dalam WIB, format `YYYY-MM-DD HH:MM`.
- **Status**: Menunggu penilaian / Valid / Duplikat / Ditolak.
- **Catatan / alasan**: untuk Ditolak, tulis alasan dari panitia. Untuk Duplikat, tulis jam link itu diklaim entri lain kalau terlihat.
- Update angka di bagian Ringkasan setiap kali status berubah.
